# 운영·판단 노트 (갤·프로·챌 글에서 모은 것)

> 글 번호는 `guide/kb/src/dc/<번호>.txt` 원문. 날짜·패치가 오래된 건 메타가 바뀌었을 수 있음 (패치 표기 확인).
> **장난글 주의**: 4189711("튕기게 해서 1등")·4194826("챌 아이디 산다")·4174019·4157726(실버 꿀덱)은 장난/어그로. 근거로 쓰지 말 것.

## 메타 읽기 (18.2b~18.5 공통으로 반복된 말)
- **연패 반등이 잘 안 되는 메타**: 확실한 근거(3스테 반등 덱, 연패 증강) 없이 2스테 연패 ㄴㄴ (4179529, 4182325).
- 러시 9가 잘 안 되고 **8렙에서 싸게 맞추고 9렙에서 5코 2성**이 흔한 그림 (4182325). 8렙이 겹치니 연승 중이라도 돈 증강 하나는 먹어야 템포가 안 밀림 (4179529).
- 첫 증강: 덱 방향을 정해주는 증강 → 대깨. 전투 증강은 '엄청난 이점'·'초월' 정도 말고 템 증강 우선. **돈+돈 먹고 밸류는 최악**. 템 증강 → 피 관리 → 마지막에 프리즘 돈 증강이나 '폭발적인 성장'이 나오면 밸류 (4179529).
- **치감과 깎(마깎·방깎)은 필수** (4182325, 4212837). 단 지옥불 덱은 화상·상처가 있어 치감 낭비 (4192320, 4190971).
- 점수가 목표면 **빈집**: A~B티어 덱도 안 겹치면 순방 (4212837). 정찰 계속.
- 3코 기물이 강한 시즌: 프로들은 1스테 크립에서 3코를 잡으면 이자 보려고 팔지 않음 (빌드업 방향 정하기·2스테 연패 방지·3코는 거의 모든 템 소화) (4182874).

## 템
- 첫 초밥: 지금 가진 재료로 **바로 완성되는 템**이 1순위. 피가 낮으면 딜러 3템 설계용 공템. 이번 시즌은 원탱 메타라 탱템 3개 + 나머지 딜템. 조끼·조개가 남으면 처리가 어려움 (4213961 댓글).
- 각 덱의 "킥" (있으면 덱 파워가 몇 배, 18.2b): 아펠 → 속사포 상징(5속사), 니달리 → 여명, 감시자 → 수맹 증강, 소라카 → 처형자/주문술사 상징·새심, 자이라 → 대천사 증강(대천사·대천사·총검), 아리 → 기원자 상징 (4179529).
- 니달리(AD): 마나템 주지 말 것. **스테락 + 무한의 대검**이 코어, 다음 정손·밤끝·피바. 로비에 베이가가 있으면 밤끝 (4181493).
- 니달리 버그: AD로 바꿀 때 마나통이 20이 아니라 AP일 때 값(40~45)으로 고정되는 버그 (2성 합칠 때 발동). 자석 제거기로 고치거나 다시 2성 (4161004, 18.1 시점).
- 아칼리: 기본은 AD (방깎템). AP는 유물(생선대가리·마나자네·새벽심장·존야·추적자의 팔목 보호대·리치베인·마법사의 최후) 있을 때. AD는 거드라·여명·새심·손도끼 좋음, 이때 밤끝 대신 스테락 (4163703).
- 카밀: 1코인데 체력 700·방마저 40, 스킬 맞히면 보호막 → 초반 탱템 홀딩은 노시너지 탱커 말고 카밀 (4182874).
- 늑대(어스름늑대): 협곡야수 켜지면 자체 정밀, 그래도 무한의 대검 (4182874).
- 기원자 아리: 감시자에게 방템 3개 주면 평균 4.14 → **3.70** (그마+, 세트에 주면 4.04) (4197093).

## 1스테이지에서 각 보기 (18.4 기준 갤 정리, 4204162)
1. 카직스 + 정손·보건·데캡 → 카직스 리롤
2. 아지르 + 구인수 → 아지르 리롤
3. 조약돌 2성 + 3협곡야수 or '두 번째 야수' 증강 → 협곡야수
4. 개화 시작 + 여눈 증강/여눈 or 악의 여단 → 기원자 아리·모르가나
5. 아칼리·카밀·바루스 2성 + 브루저템 → 아칼리 카밀 리롤
6. 베이가 2성 + 보건·블루 → 베이가
7. 전쟁기계 페어 + 대천사 증강 → 전쟁기계 자이라
8. 지옥불 시작 + 브루저템 → 니달리 아펠

## 덱별 메모
- **베이가 리롤** (4214447, 4171871): 2스테 5연패 → 3-1에 30골까지 48리롤 → 3-2 베이가 3성 (렉사이·오른 장수 많으면 같이). 베이가 보건·블루·총검 (루덴·마나자네·새심). 1스테에 베이가·렉사이 장수 + 여눈.
- **기원자 아리** (4214447, 4182325): 아리 보건+마나템, 모르가나 공지·모렐(+레드/적투), 감시자 수맹/적투. 감시자가 인기라 2성이 늦으면 힘듦.
- **6전쟁기계 자이라** (4193824, 4182325): 4-1 시작하자마자 8렙, 자이라 독박딜 → 쇼진·대천사·딜템, 이온·썬파. '고위천사' 대천사 증강이면 날먹. 8렙 마오카이 한 장이면 우승권.
- **협곡야수** (4212837): AP템은 조약돌, AD템은 묘목 3성 아니면 어스름늑대. 버프는 바위게/돌거북(상대 치감 보고 전투 직전 변경). 조약돌 3성 + 3템이면 감시자에 고정. 9렙 나르·타릭 또는 10렙 10협곡야수.
- **나무정령**: `set18.md` 나무정령 항목.
- **마스터 이 배치** (4212109): 상대 원탱이면 1열에 6명 깔고 마이가 빈 공간으로 돌아가게 → 렝가가 움직이며 타게팅 초기화 → 뒷라인부터.
- **케이틀린 리롤** (4182325): 2스테 망했을 때. 쭉 연패라 악의 여단 탈 수 있으면 탄다. 최대 4등 노리는 덱.

## 상징 증강 (2026-11-01 정리)
- 2-1 상징 증강은 MetaTFT 18.5c 기준 대부분 S티어: 가지 뻗기, 뻗어가는 뿌리, 특성 나무, 전략가의 주방 (전방의 토대·후방 설계도·유연함·3단계 군단은 A). 첫 증강 선택률도 가장 높음 (4182325).
- **2-1에 상징이 센 덱을 가리키면 그 덱으로 가는 게 정석** ("첫 증강 덱 방향 정해주는 증강 먹고 대깨" 4179529, "상징 먹고 특정 덱 대깨가 편함" 4155554). Explorer 플래+: 아펠 4.35 → 나무 상징 단 아펠 4.03, 아리 4.46 → 기원자 상징 단 아리 4.31. 억지로 맞추면 안 되는 경우만 조심: 꽝 상징(악의 여단·검은 가시·날렵이), 이미 2성·템이 다른 덱을 강하게 가리킬 때, 3-2에 덱이 정해진 뒤. 그땐 재조합기 (4182874, 4215203).
- 3-2 '+' 버전: 가지 뻗기+·특성 나무+는 재조합기가 같이 와서 무난. **뻗어가는 뿌리+는 재조합기 없이 3-2에 상징 2개라 위험** (4171871).
- 협곡야수처럼 지역 시너지를 못 쓰는 덱은 상징 증강을 재조합기가 있을 때만 (4194979).
- 상징 → 덱 (갤·롤체지지 [상징] 덱):
  - 나무정령 → 아펠에게 (이즈·아펠 8렙 7나무) / 속사포 → 아펠 5속사 / 기원자 → 아리·알룬 / 처형자 → 소라카·아리·햇빛 유나라 / 주문술사 → 소라카
  - 요정 → 트리스타나 리롤(4요정) / 사냥꾼 → 아칼리·AD 니달리 / 엄호대 → 카시오페아·렝가 / 싸움꾼 → 마스터 이 / 전쟁기계 → 6전기(짜바리 빼고 케넨·아이번·타릭) / 지옥불 → 애쉬·럭스 / 검은 가시 → 카직스 / 치명적인 꽃 → 베이가, 이즈리얼(적투)
- 상징 아이템 성적 (MetaTFT 최종 보드에 단 판, 18.5c 플래+): 싸움꾼 4.11·선봉대 4.10 A / 나무정령·달빛·처형자·전쟁기계 4.21~4.23 / … / 날렵이 4.54, 검은 가시 4.63, **악의 여단 5.05(D)**. 골드↓에서는 나무정령 3.98·싸움꾼 3.97·선봉대 3.98이 제일 좋음. 꽝 상징(악의 여단·검은 가시·날렵이)은 재조합기 우선.

## 엄호대 렝가 / 엄호대 카시 (2026-11-05)
- **엄호대 렝가 = 엄호대 상징 덱**: MetaTFT 그 덱 판의 98%가 엄호대 상징, 96%가 렝가에게 (렝가는 원래 경쟁자). 평균 4.18, 플래+·에메+·다이아·마스터+ 모두 S. 상징 없이는 이 덱이 아님.
- 왜 렝가에게: 카시 스킬로 깎아두고 렝가가 막타(갤 4215203). 렝가 3신기 = 엄호대 상징·구인수·거인의 결의 (4214447), 상징 있으면 오른 빼고 렝가.
- 상징 없으면 **엄호대 카시오페아**(오른 자리 그대로, 피들·람머스 탱): 평균 4.57로 B, 다이아·마스터+에선 C. 갤 마스터 공략(4214447): 엄호대 상징 / 역병의 보석 / 고위천사 지팡이 셋 중 하나 없으면 이 덱 가지 말 것. 람지르랑 람머스·피들 겹침 주의.

## 햇나라 (햇빛 카르마 유나라, MetaTFT '개화 카르마') (2026-11-05)
- 6렙 리롤: 3성 5개 = 요릭(1)·카르마(1)·유나라(2)·르블랑(2)·세주아니(2). 8렙에 레오나(1)·케일(2) 넣어 3햇빛(세주·레오나·케일) + 처형(유나라 + 처형자 상징이면 더 좋음).
- 성적(MetaTFT 3일): 플래+ 4.47 A, 마스터+ 4.35 A, 그마·챌 4.31 A, **플래 미만 4.75 C** → 고티어에서 잘 되고 저티어에선 어려운 덱. 11/5 그마·챌 최근 1등 75판 중 4판.
- 템: 유나라 죽검·쇼진·라위(또는 거학/무대), 카르마 블루·보석·라바돈, 세주아니 가고일2·워모그, 르블랑 공허·레드.
- 갤 공략(4204842): 각 = 2-1에 요릭·카르마·유나라로 3개화가 바로 켜지는 것 (템은 상관없음, 기물 장수가 전부). 돈 증강은 1개 이하, 스포트라이트·도전자의 은총 같은 공격 전투 증강 좋음, 초월·남작의 소굴 같은 버티기 증강 나쁨. 3-5엔 6렙 올 2성 + 템 2~3개, 3~4라를 이겨야 함. 5라 초반까지 유나라·세주·르블랑 3성 목표 리롤, 카르마·요릭은 장수 많을 때만 시작. (이 글쓴이는 18.4 때 6~7렙에 아지르로 처형을 켜는 변형이라 '처형자 상징 있으면 7렙에 아지르 빼고 레오나·케일'이라고 씀. **지금 표준 보드는 7렙에 아지르가 없다**: 5렙부터 레오나, 7렙 = 세주·레오나·요릭·카르마·유나라·르블랑·케일(3햇빛), **아지르는 8렙**에 처형 켜려고 들어옴 — 롤체지지 레벨별 보드·MetaTFT 둘 다 같음. 2026-11-05 사용자 지적.) 8렙 3햇빛만 받아도 거의 순방. 르블랑이 복사해줘서 마지막 3성이 잘 찍힘.
- 롤체지지 추천 증강: 교환의 장, 프리즘 티켓, 유리 대포 II.

## 4코 3성 vs 밸류 (2026-11-06 연구, 롤체지지 랭크 12,892로비 · 세트 18 18.3b~18.6 · 전 티어)
- 정의: 4코 3성 = 4코 3성 1개 이상, 5코 3성 없음. 밸류 = 4·5코 3성 없는 덱을 레벨과 5코 2성 수로 나눔. 판 기록은 최종 덱(탈락 시점 덱)이라 일찍 죽은 사람 덱은 약하게 남는다 → **공정 비교는 끝까지 남은 1·2등 1:1**.
- 얼마나 나오나: 4코 3성 덱 1,385판 (전체 보드의 1.3%). 나오면 평균 1.23등 · 1등 85% · 순방 99%.
- 밸류 성적: 10렙 1.99등 (1등 47%) · 9렙 5코 2성 3+ 2.81등 (33%) · 9렙 5코 2성 1~2 3.74등 (16%) · 5코 2성 없음 4.33등 (9%).
- **마지막 1:1에서 4코 3성이 이긴 비율**: 5코 2성 없는 밸류 상대 97% (493번) · 9렙 5코 2성 1~2 96% (258) · 9렙 5코 2성 3+ 94% (160) · 10렙 90% (235). 10렙 중 5코 2성 5개+ 상대로도 84% (49).
- 티어별 차이 거의 없음: 골드 이하·플래·에메·다이아 96%, 마스터+ 93% (고티어일수록 밸류가 조금 더 버팀).
- 4코 3성 유닛별 (밸류 상대, 같은 로비 전체): 덩굴정령(협곡야수 4코) 100% · 세트 99% · 시비르·감시자·이즈리얼·모르가나 98% … 니달리(AP) 93%. 캐리(3템)든 아니든 큰 차이 없음 (캐리 아님은 표본 54판).
- 한계: 4코 3성을 찍는 사람은 이미 이기고 있는 경우가 많아 (돈·체력 여유) 순수한 '덱 힘'만은 아니다. 증강·배치·체력은 판 기록에 없다. 4코는 종류당 10장이라 3성(9장)은 경쟁자가 있으면 거의 불가능 (`숫자` 탭 기물 장수).
- 결론: 최종 덱끼리는 4코 3성이 10렙 밸류까지 90% 이상 이긴다. 밸류가 4코 3성을 이기는 경우는 10렙에 5코 2성 5개 이상일 때도 6판 중 1판꼴.

## 4코 3성 1개 + 나머지 짜바리 (2026-11-07, 18.6·18.5c 9,396로비)
