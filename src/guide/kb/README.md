## 쌓는 법
- 새 사실을 알게 되면(사용자 지적 포함) `sources.md`의 파일 라우팅 표에 맞춰 맞는 파일에 추가(날짜·출처 필수). 틀린 걸 고치면 `corrections.md`에도.
- 매일 예약 점검 시 `sources.md` 2절 프로토콜대로 `r/CompetitiveTFT`·DC 롤체갤·(PBE 빌드/패치 시) `tftflow.com`(`scripts/tftflow_diff.py`)·공식 패치노트를 스캔해 검증된 팩트만 승격한다.
- 갤 글: `python3 scripts/dc_crawl.py list 1` (인자 = 쪽 수) → 쓸 만한 걸 `get` → `strategy.md` 또는 `set19.md`에 요약 + 번호.
- 패치마다 `set19.md`와 `strategy.md` 메타 항목을 손본다.
