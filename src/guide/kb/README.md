# 롤체 지식 노트 (꺼내 쓰는 곳)

답하기 전에 여기부터 찾는다: `python3 scripts/kb.py 키워드 [키워드...]`

| 파일 | 내용 |
|---|---|
| `rules.md` | 게임 규칙 숫자: 골드·이자·연승연패·경험치·상점 확률·기물 수·피해량, 판매 가치, 템 규칙(재조합기·제거기·복제기·망토) |
| `set18.md` | 이번 세트 시너지 숨은 조건·운영 (수호령, 나무정령, 악의 여단 캐시아웃 표, 협곡야수 등) |
| `strategy.md` | 메타 읽기·첫 초밥·덱별 킥·1스테 각 보기·덱별 템/배치·버그 (갤 글 근거, 번호 표기) |
| `corrections.md` | 내가 틀렸던 것 |
| `dc_index.md` | 갤 개념글 목차 (원문 `src/dc/`) |
| `sources.md` | 데이터 사이트, 유튜브 영상 목록 |

숫자 데이터(덱·유닛·템·증강 원문, 통계)는 `guide/data/`. 갱신 주기가 다르니 섞지 않는다.

## 쌓는 법
- 새 사실을 알게 되면(사용자 지적 포함) 맞는 파일에 한 줄 추가. 틀린 걸 고치면 `corrections.md`에도.
- 갤 글: `python3 scripts/dc_crawl.py list 20` → 쓸 만한 걸 `get` → `strategy.md`에 요약 + 번호.
- 패치마다 `set18.md`(세트가 바뀌면 새 파일)와 `strategy.md` 메타 항목을 손본다.
