## 아이템 규칙
- **뒤집개(Spatula) ↔ 프라이팬(Frying Pan): 재조합기를 쓰면 서로 바뀐다** (14.18부터. 시즌 18에서도 그대로, 사용자 확인 2026-11-01). 상징에 재조합기를 쓰면 무작위 상징.
  - 나무정령 상징 = **뒤집개** + 쇠사슬 조끼. 프라이팬으로는 못 만듦 → 프라이팬이 있으면 재조합기로 뒤집개로 바꿔서 만든다.
  - 프라이팬 상징 (12_상세_아이템 참고): 기원자(+여눈), 사냥꾼(+대검), 선봉대(+조끼), 속사포(+곡궁), 싸움꾼(+허리띠), 처형자(+장갑) 등.
- **전략가의 망토**(뒤집개+프라이팬)·**전략가의 방패**(프라이팬+프라이팬): 팀 인원 +1. **전략가의 왕관**(뒤집개+뒤집개).
- **재조합기**: 장착한 템을 모두 빼고 비슷한 유형·등급의 다른 템으로 바꿈 (조합템→조합템, 재료→재료, 상징→상징).
- **자석 제거기**: 템을 모두 뺌 (전투 중 불가). **황금 제거기**: 몇 번이든 뺌 + 이후 자석 제거기를 모두 재조합기로 바꿈.
- **챔피언 복제기**: 1성 복사본. **하급 복제기**: 3코 이하만.
- 재조합기 얻는 곳: 증강 '최적화'가 준다는 갤 글 (DC 4214708, 확인 안 됨). 그 외 초밥·보상 운.
- 스택형 템(구인수·거인의 결의·대천사·크라켄) 버그: 평타를 쳐야 스택이 쌓이는 기물이 있음 → 3·4열에 두는 덩굴정령 같은 기물한테는 손해 (DC 4208813, 18.4 시점).

- 사거리 안의 **탱커 기물을 먼저** 노리고, 그게 죽으면 **가장 가까운** 기물을 노린다.

## 전략가의 시험 (Tactician's Trials) 뽑는 기준 — 세트 18 APAC 1차 (Liquipedia, 2026-11-05 확인)
- 정해진 날의 **랭크 순위표 스냅샷**으로 뽑음. 한국: **1~10위 → 2주차 3일차 직행**, **11~122위(112명) → 1주차 1일차**. 한국 아마추어 대회 상위 2명도 2주차.
- 1주차(1~2일차): 112명 6판 → 56명 → 6판 → 상위 28명 2주차. 날마다 점수 초기화.
- 2주차(3~5일차): 128명 → 64명 → 32명 → 마지막 날 8명씩 탈락. **최종 8명 = 지역 결승 1주차**, 9~16위는 예선 포인트 + 다음 시험 3일차 직행. 예선 포인트 상위 4명은 지역 결승 플레이인.
- 한국어 이름: 앱은 전략가의 시험 / 전략가의 왕관(월즈)로 표기 (사용자 요청). 공식 한국어 명칭은 확인 못 함.

## 월즈(전략가의 왕관) 진출 경로 (세트 18, Liquipedia Enchanted Wilds/Tacticians Crown/Qualification, 2026-11-05)
- 40명: AMER·EMEA·APAC은 지역마다 프로 서킷 컵 3개(협곡야수·나무정령·개화) 우승자 + 프로 포인트 1위 + 지역별 결승 상위 N명 (AMER 5, EMEA 5, APAC 7). 중국은 TOC·JOC 프로 서킷 우승 각 1 + 중국 나무정령 컵 우승 1 + TOC·JOC 지역 결승 상위 4명씩.
- 중복 진출(컵 우승자가 결승 상위권)이면 그 결승 자리는 다음 순위로 내려간다. S18: seoill(협곡야수 컵) → APAC 결승 1위 자리는 8위 iCeEmperoz, Cambulee → AMER 6위 JosueDeleted, Bensac(포인트 1위) → EMEA 6위 whyyoumadpro.
- 한국 선수는 seoill 1명 (APAC 협곡야수 컵 우승, 지역별 결승 우승, 프로 포인트 2위).

- 페이지: `build_esports.py crown_roster()`가 하루 한 번 Qualification 페이지를 다시 받아 `esports.json`의 `crown`으로 (월즈 끝나면 안 받음).

## 필드 가치 · 덱파워 (앱 전적 카드, 2026-11-05)
- 필드 가치 = 보드 유닛 골드 합: 1성 코스트, 2성 ×3, 3성 ×9 (5코 3성 혼자 45). MetaTFT 데스크탑의 왼쪽 숫자와 같은 개념.
- 덱파워 = 판 끝 보드로 예상 등수를 내는 릿지 회귀 (`scripts/build_power.py`, 롤체지지 랭크 판). IQ식: 100 = 평균, 15 = 1표준편차 (2026-11-06 사용자 요청으로 50→100 기준 변경). 130↑ 무지개(상위 ~2%), 125↑ 금색. 같은 로비 등수 순서 맞춤(스피어만) ≈ 0.86, 순방 여부 ≈ 87% (필드 가치만 쓰면 0.71·78%). 레벨 10/9, 4코 3성, 전략가의 왕관·망토, 찬란한 템, 유물이 크게 올린다.
- 한계: 판 끝(탈락 시점) 보드 기준이라 일찍 죽으면 보드도 약하게 남는다. 배치·증강·골드는 안 들어간다. 게임 중 실시간 아님.
- 덱파워 '레벨' 항목 검증 (2026-11-06, 최근 3주 6만여 보드): 실제 평균 등수 7렙 5.75 · 8렙 4.84 · 9렙 3.79 · 10렙 1.94. 모델의 레벨 점수(평균 대비 8렙 −1, 9렙 +8, 10렙 +16)는 유닛·템으로 설명 안 되는 몫만이다. 5렙이 6렙보다 높게 나오던 뒤집힘은 레벨 점수를 높을수록 줄지 않게 고정해서 고침. 빈자리 손해는 대부분 '유닛' 점수(빠진 유닛 골드·별)에서 빠지고 레벨 쪽엔 −1~−3만 남는다. 레벨+2자리(왕관·협곡야수 10)는 +7~8 (9렙 실제 3.78등→3.10등).

## 덱파워 재검토 (2026-11-06, 최근 3주 8,059로비 · 테스트 1,611로비)
- 모델 비교 (테스트 로비): 등수 회귀(릿지) 1등 맞춤 65.2%·8등 67.5%·두 덱 비교 88.7% / **Plackett-Luce 순위 모델 70.2%·71.8%·89.5%** / LightGBM 비선형 71.0%·69.0%·89.5% / 둘 섞기 71.9%·71.0%·89.7%. 필드 가치만 48.4%·55.7%·79.6%. → 선형 순위 모델로 바꿈 (비선형과 거의 같고 페이지가 가중치 합으로 계산 가능).

## 덱파워 압도 보정 (2026-11-06, 사용자 "4코 3성 세트가 쳐바를 텐데 147 동점은 이상")
- 학습(Plackett-Luce)은 로비 8명 전체 순서를 맞춰서, 1등을 거의 확정하는 덱을 덜 쳐줬다. 같은 덱파워 145~160: 4코 3성 1.08등(1등 93%) vs 일반 1.25등(75%). 프리즘 시너지 130~145 30판은 전부 1등.
- 반복 늘리기(400 -> 1500)와 '가장 센 유닛'·'3성 개수' 특징 추가는 효과 없음 (1등 맞춤 70% 그대로, 유형별 오차 그대로).
- 일반 덱은 덱파워가 올라도 1등 확률이 80%대에서 멈춘다 (160: 81%, 200: 86%). 4코 3성·프리즘 덱은 90~100%.
- 고침: `fit_adj`가 유형(a4:1 4코 3성, a4:2 4코 3성 2개+, ap 프리즘 시너지)마다 덱파워 구간별 '같은 1등 확률을 내는 일반 덱 덱파워와의 차이'를 표로 만들어 더한다 (표본 적으면 n/(n+20)로 줄임). 여러 유형이면 큰 쪽 하나. 5코 3성 상한(f5) 아래는 30점 전부터 순서를 지키며 눌러 담는다(`cap5`).
- 보정 뒤 같은 구간 비교: 145~160 4코 3성 예상 1.24 → 실제 1.31, 일반 1.26 → 1.22 (거의 맞음). 화면 대조: 덱파워 탭 100판 불일치 0, 전적 카드 10판 불일치 0.
- 판 4,005로비 더 모음 (8,917 → 12,892, 학습 9,396로비 18.6·18.5c). 매일 점검 수집 300 → 1,500. 덱파워 탭 목록은 power.json과 같은 반올림 가중치로 계산 (경계에서 1점 어긋나던 것).
- 예: 패배에서교훈을(세트 4코 3성) 147 -> 179 (예상 1.13등), 초보끼리합시다(1·2코 3성) 147 -> 143.

- **4등 +10, 5등 -10은 거의 고정**: 플래+ 4등 174판 중 155판이 정확히 +10, 5등은 대부분 -10.
- **1~3등·6~8등만 MMR에 따라 움직인다**: 같은 플래+라도 사람마다 1등 중앙값이 33~60. MMR이 지금 티어보다 높으면 더 받고 덜 잃는다 (저티어 1등 +63·8등 -24가 그 예: 실력보다 낮은 티어에 있는 사람이 많다).
- **한 판에 구간(디비전) 0LP 아래로는 안 떨어진다**: 구간 1~20LP에서 6~8등 176판 중 139판이 그 구간 0LP에서 멈춤.

- 마스터+는 로비가 셀수록 1등 LP가 조금 적은 경향(+48 → +43)이 보이지만 표본이 작다.
