# 앱 디자인 기준 (v1.42.0, 2026-11-07)

근거: 롤체지지·MetaTFT·tactics.tools·TFT Academy 모바일 화면을 직접 찍어 비교(전부 어두운 남색 바탕 + 금색·노랑 강조), Apple HIG(기본 17pt, 최소 11pt), Material 다크 테마(순검정 대신 어두운 회색, 층은 그림자 대신 밝기, 큰 면에 밝은 색 금지), Refactoring UI(위계는 크기·굵기·색, 테두리 남발 금지), 토스(강조색 하나, 한 화면에 강조 행동 하나).

## 색
- 다크: 바탕 `#0a0d14`, 카드 `--surface #121722`, 카드 안 한 단계 위 `--raise #1a2030`, 선 `--line #1c2230`(거의 안 보이게).
- 라이트: 바탕 `#f2f4f6`, 카드 흰색, 선 `#e9ecf0`.
- 켜진 상태(칩·탭·목록 선택·큰 버튼)는 `--on-bg`/`--on-ink` 하나만: 다크 금색, 라이트 검정. 초록(`--moss`)은 "좋음" 뜻으로만.
- 티어 색: S `#ff5a5f` · A `#ff9f1a` · B `#2fbf7f` · C `#4b9dff`. 덱 줄 왼쪽 막대 + 은은한 번짐(`.dk`, opacity .22).
- 난이도는 칩 대신 글자색(`.dd1~4`).

## 덱 줄 (`.mt-row.dk`)
- 메인 캐리 육각형 초상(56px, 테두리 = 코스트 색) + 왼쪽 위 티어 + 아래 캐리 템 3개 (`dkPortrait`, `mainOf`).
- 이름 16px 굵게 / 운영·난이도 12px 회색 / 나머지 유닛 24px / 오른쪽 숫자 20px.
- 시너지 육각형은 목록에서 빼고 상세에만.

## 상세 머리 (`.dk-hero` + `.dk-kpi`)
- 메인 캐리 그림을 오른쪽에 흐리게 깔고, 티어 배지·덱 이름 22px·운영 줄. 그 밑에 큰 숫자 3칸(평균 등수는 금색, 순방, 승률).
- 큰 버튼(`.codebtn.big`)은 강조색, 모서리 14px.

## 앱 전체 (v1.43.0)
- 카드 테두리는 투명(`border: 1px solid transparent`, 크기 유지). 바탕과 카드의 밝기 차이로만 구분.
- 탭 전환은 `.seg`·`.seg2` 둘 다 같은 모양: 어두운 홈 안에 켜진 칸만 카드색.
- 티어 배지 `.tierb` S·A·B·C는 덱 줄과 같은 색, 글자는 어둡게.
- 티어가 있는 줄(아이템 티어표 등)은 `.tbar t-<티어>`: 왼쪽 막대 + 번짐.

## 조작 줄
- 덱 목록 위 조작은 3줄 이하: 탭(추천·전체·최근 1등) / 거르기 칩 + 정렬 목록 / 검색·기준.

## 겹침
- 스크롤되는 카드 안에서 z-index를 쓰면 카드에 `isolation: isolate`. 고정 바는 z-index 6 (카드 안 요소보다 위, 상단 바 8·아래 메뉴 9보다 아래).

## 업데이트 시각
- 데이터가 있는 탭은 맨 위에 `.mt-upd` 한 줄: `11/7 13:54 업데이트 · 1분 전 · 출처`. 앱에서 바로 받을 수 있으면 오른쪽에 새로고침 버튼 (덱·아이템·한국 랭킹·친구).

## 숫자 칸이 여러 개인 목록
- 같은 급 숫자가 둘 이상이면(승률·순방률 등) 같은 크기로 칸을 나란히 두고, 칸 이름은 머리줄 하나에 적어 `position: sticky`로 고정한다 (줄마다 이름표를 붙이지 않는다). 2026-11-07: 머리줄이 스크롤로 사라져서 줄마다 이름표를 붙였더니 승률이 작아지고 글이 헷갈렸다 → 사용자 지적으로 고정 머리줄로 바꿈.
- 숫자가 하나뿐인 목록(덱 줄)은 큰 숫자 + 밑에 작은 보조 숫자.

## 좁은 화면
- 한 칸 grid 카드 안에 줄바꿈 없는 글(`white-space: nowrap`)을 넣으면 카드 최소 폭이 커져 화면이 옆으로 밀린다. 카드에 `grid-template-columns: minmax(0, 1fr)`. 바꾼 화면은 360·393·412 폭에서 문서 폭이 화면 폭과 같은지 확인한다.

## v2 (v1.50.0, 2026-11-10) — 사용자: "상용급 이상으로, 다 갈아엎어도 됨"
페이지 `<style>` 맨 끝 '디자인 v2' 블록이 앱 전체를 덮는다 (구조·JS는 그대로, 겉모습 층만). 새 화면도 이 규칙으로.
- **깊이**: 카드 `--r-card: 18px` + `--shadow` (다크는 위쪽 1px 하이라이트 + 깊은 그림자, 라이트는 부드러운 그림자). 바탕 위쪽에 은은한 금빛 번짐.
- **유리**: 상단 바는 반투명 + 블러. 아래 메뉴는 화면에서 떠 있는 알약 (좌우 12px 띄움, 켜진 탭은 금색 알약 배경).
- **색 테두리 금지**: 왼쪽 색 테두리 카드(판 카드·친구·덱파워·월즈 진출자)는 그 색이 135도로 은은하게 번지는 배경으로. 등수 배지는 46px에 색 그림자.
- **조작**: 칩은 알약, 켜진 칩은 색 그림자. 세그먼트 14px. 큰 버튼 16px + 색 그림자.
- **움직임**: 탭 전환 0.24초 올라오며 나타남, 누르면 0.975로 살짝 줄어듦 (`prefers-reduced-motion`이면 전환 없음).
- **제목**: 섹션 제목 16~17px 800, 덱 상세 제목 24px, 큰 숫자 22~24px.
- 더보기 타일: 아이콘을 금색 옅은 바탕의 둥근 사각형 안에.

## 탭 구조 (v1.51.0)
- 자주 번갈아 보는 화면은 한 탭 안의 보기 전환으로 묶지 않는다 (전환하면 서로의 상세·위치를 잃는다). 따로 탭으로 두고, 탭마다 상태와 스크롤을 남긴다.
