# 롤체 노트 문구 기준

앱에 들어가는 모든 글(버튼, 제목, 설명, 상태, 빈 화면, 알림, 버전 노트)은 이 기준을 따른다.
목표는 **상용 앱처럼 읽히는 것**. 사람이 만든 서비스의 말투로, 짧고 정확하게.

근거: [토스 8가지 라이팅 원칙](https://toss.tech/article/8-writing-principles-of-toss) (잡초 뽑기, 빈 문장 빼기, 핵심만, 말하듯, 강요 대신 제안, 누구나 아는 말, 예측 가능한 힌트, 숨은 감정), [Material 글쓰기](https://material.io/design/communication/writing.html) (명확·정확·간결, 필요 없는 문장부호 빼기, 단독 문장 마침표 생략), [앱인토스 UX 라이팅](https://developers-apps-in-toss.toss.im/design/ux-writing.html).

## 1. 말투

- 문장은 **해요체**. 반말·명령조·"~습니다" 섞지 않는다.
- 버튼·탭·칩·표 머리는 **명사형**: `갱신`, `전적 보기`, `덱파워 순`. "~하기"는 동작이 헷갈릴 때만.
- 느낌표, 이모지, 유행어·은어·밈(괴물, 꿀, ㄹㅇ, 미쳤다, 사기)은 쓰지 않는다. 게임 용어(리롤, 순방, 3성, 템)는 써도 된다 — 사용자가 매일 쓰는 말이다.
- 비유로 설명하지 않는다 ("IQ처럼", "지도마냥"). 숫자의 뜻을 바로 적는다.
- 농담·감탄·호들갑 없음. 숫자가 크면 숫자가 말하게 둔다.

## 2. 덜어내기 (AI 티 나는 것들)

| 이런 건 빼거나 고친다 | 이유 |
|---|---|
| 괄호로 덧붙인 속사정 `(매일 아침 새로)`, `(추정)` 남발 | 사용자가 몰라도 되는 내부 사정. 꼭 필요하면 별도 줄이나 도움말로 |
| `·`로 4개 넘게 이어 붙인 문장 | 읽히지 않는다. 핵심 2~3개만 |
| `→` 화살표로 문장 잇기 | 흐름도가 아니면 문장으로 |
| 출처·방식 자랑 `롤체지지 실시간 · 수천 판 학습` | 출처는 화면 맨 아래 한 번, 작게 |
| 기능 설명을 화면마다 반복 | 처음 보는 곳 한 번, 나머지는 도움말(ⓘ) |
| `눌러서 ~`, `~하면 ~돼요` 사용법 안내 | 누를 수 있게 생겼으면 안내 불필요. 숨은 동작만 짧게 |
| 단위·숫자 범위 나열 `115↑ 잘함 · 125↑ 금색 · 130↑ 무지개 · 145↑ …` | 색이 이미 보여준다. 기준 설명은 도움말로 |
| 빈 문장 `분석해 드릴게요`, `확인해 보세요`, `참고하세요` | 아무 기능이 없다 |
| 같은 말 두 번 (`덱파워 · 덱파워 상위`) | 한 번만 |

## 3. 용어 (이렇게 통일)

| 쓴다 | 안 쓴다 |
|---|---|
| 최종 덱 | 판 끝 보드, 마지막 보드, 끝난 보드 |
| 필드 가치 | 보드 골드, 유닛 골드 |
| 덱파워 | 세기, 파워 점수 |
| 상위 3% / 하위 20% | 3퍼, 3%급 |
| 평균 등수 · 순방률 · 승률 | 평등, 탑4율 |
| 업데이트 시각 `11/6 07:57 업데이트` | `기준`, `받음`, `갱신됨` 섞어 쓰기 |
| 불러오는 중 | 받는 중…, 로딩 |
| 불러오지 못했어요 | 못 받았어요, 실패 |
| 랭크 게임 | 랭겜 |
| 롤체지지 · MetaTFT · tactics.tools (출처 이름 그대로) | 닥지지 |

## 3-1. 품격 있는 단어 선정 (짜치는 구어체·번역투 금지, 2026-11-20 사용자)

상용 서비스의 완성도를 해치는 구어체·아마추어 표현은 절대 쓰지 않는다. 모든 화면·알림·업데이트 소식·스크립트 자동 생성 문구에 기본으로 적용한다.

| 쓰지 않는다 | 이렇게 쓴다 |
|---|---|
| `새로 A티어`, `새로 C티어` | `A티어 진입`, `C티어 진입` |
| `B→S티어 상승`, `S→A티어 하락` | `B → S티어`, `S → A티어` (화살표 공백, 중복된 상승/하락 생략) |
| `빠짐 (전에 A티어)` | `티어표 제외 (이전 A티어)` |
| `팁 바뀜`, `배치·템 바뀜` | `팁 변경`, `배치·템 변경` |
| `갈 덱`, `갈 만한 덱` | `추천 덱` |
| `비우기` | `초기화` |
| `담기` / `빼기` / `넣었어요` / `뺐어요` | `추가` / `제외` / `추가했어요` / `제외했어요` |
| `가장 비싼 칸`, `훑어요`, `덱의 뼈대` | `최상위 7코스트`, `먼저 익혀 보세요`, `조합의 중심` |
| `못 찾았어요` | `찾을 수 없어요` |
| `예전 세트에 있던 이름` | `이전 시즌에서 복각된 시너지` |

## 4. 화면별 규칙

- **제목**: 2~6자 명사. 부제가 필요하면 한 줄, 25자 안.
- **설명 문단**: 화면 맨 위 한 번, 두 문장 안. 숫자 기준표는 도움말 시트로.
- **상태**: `불러오는 중`, `불러오지 못했어요. 다시 시도해 주세요`, `아직 기록이 없어요`. 원인은 사용자가 할 수 있는 게 있을 때만.
- **업데이트 시각**: `11/6 07:57 업데이트` 형식. 주기 설명 안 함.
- **출처**: 리스트·표 맨 아래 `출처 롤체지지` 한 줄.
- **툴팁·길게 누르기**: 한 문장. 숫자 정의는 여기에 둬도 된다.
- **버전 노트**: 바뀐 것만, 항목당 한 줄. 이유·배경 설명 없이. `~했어요` 대신 `~` 명사형 끝맺음도 된다.

## 5. 고친 예

| 전 | 후 |
|---|---|
| 판 끝 보드가 얼마나 셌나: 💰필드 가치(유닛 골드) · 덱파워(IQ처럼 100 보통 · 115↑ 잘함 · … · 145↑ 괴물). 숫자를 누르면 … | 최종 덱의 강함을 점수로 보여줘요. 100이 평균이에요. |
| 롤체지지 랭크 판 · 최근 7일 판 끝 보드 중 덱파워 상위 · 11/5 12:07 기준 (매일 아침 새로) | 최근 7일 · 11/5 12:07 업데이트 |
| 💡 일반 유저가 월즈 가는 길: 한국 랭크 상위 → 시험 상위 8명 → 지역별 결승 → 결승 상위권 | 일반 유저는 한국 랭크 상위권에서 전략가의 시험, 지역별 결승을 거쳐 월즈에 갈 수 있어요. |
| 덱파워 · 상위 0.74% · 예상 1.0등 | 상위 0.74% · 예상 1.0등 |

## 6. 고치기 전에 확인

1. 소리 내어 읽었을 때 사람이 하는 말인가
2. 이 단어를 빼도 뜻이 같은가 → 빼기
3. 이 문장이 없어도 화면을 쓸 수 있는가 → 빼기
4. 이모지·느낌표·비유·농담·괄호 속사정이 있는가 → 빼기
5. 같은 화면에 같은 말이 두 번 있는가 → 하나로

## 선택률 (2026-11-14 사용자)
- 덱을 로비에서 평균 몇 명이 하는지는 **선택률**로 쓴다 (MetaTFT Pick Rate, 소수 둘째 자리 `선택률 0.62`). "한 판 N명", "픽률 N%"는 쓰지 않는다.
