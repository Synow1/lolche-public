# 롤체 한 장 요약 (18.5b) — 캡처해서 보기

**판 시작** → 조우자 확인 → 1스테이지에 페어 모으기, 크립 3코는 2-1까지 들고 가기

**2-1 질문: "2라를 세게 갈 수 있나?"** (2성 기물 + 줄 템 + 시너지 + 증강)
- **YES**: 템·전투 증강 → 2-1 4렙 / 2-5 5렙 연승
- **NO**: 돈 증강 → **2-1 10 / 2-2 20 / 2-3 30 / 3-1 50골**. 핵심 기물만 남기고 다 팔기
- 근거 없는 연패 금지 (예외: 악의 여단, 지옥불, 나 혼자 연패 증강)

**레벨업**: 2-5 5렙 · 3-2 6렙 (20골 이하 남으면 3-5까지 참기) · 4-1 7렙 · 4-2 8렙 · 5-1 9렙
- 3-5 7렙은 40골 남을 때만. 3-6 크립 롤 = 충동 롤
- **4-1 8렙** = 경쟁자 있을 때 / **4-2 8렙** = 빈집일 때
- **0원 올인** = 피 30~40 이하 or 경쟁자 있음. 아니면 **30골 남기기**

**리롤 레벨**: 1코 → 4렙(3-1 48리롤, 33골까지) · 2코 → 6렙 · 3코 → 7렙 · 4코 → 8렙 · 5코 → 9렙

**수호령(=주술)**
- 2성 상점은 무조건 사기: **시작 마을**(1코) · **변경 마을**(2코) · **중도**(3코)
- 2코 리롤은 3-1부터, 3코 리롤은 3-5부터 매 라운드 확인
- 돈 털 턴엔 0~1원 아무거나 사서 칸 막지 말기
- **3-5부터 수금·소매치기**가 떠요. 3-5·3-6에 리롤 섞어서 잡으면 판이 터져요

**템**
- 메인딜 3템 집착 + 나머지 탱템 / 메인탱 + 메인딜 + 서브딜 구조
- **치감 + 깎(방깎·마깎) 필수**
- 조합템 5개 이상 쌓이면 지금 만들기
- 구인수 + 크라켄 같이 쓰지 말기 (자야·케틀·드븐 제외) / 조약돌한테 적투 금지

**증강**: 템 > 돈 > 전투. 부족한 걸 채우는 걸 고르기. 돈돈 먹고 밸류 = 최악

**정찰**: 2-1 증강 직후 · 3-2 전 · 4-1/4-2 롤 전. 4코는 종류당 10장 → 남은 장수 세기
- 겹치면 먼저 롤해서 선점하거나, 상대가 빼줄 때까지 기다리기
- 3팀이 쓰는 기물은 포기

**내 덱 (18.5b)**
| 덱 | 언제 | 핵심 템 |
|---|---|---|
| 협곡야수 덩굴정령 (8렙) | 조약돌 2성 + 3협야. 협야 2명 이상이면 패스 | 덩정: 구인수 / 밤끝 / 정손 |
| 기원자 티모·알리스타 (6렙) | 쇼진·보건 재료 + 티모·알리·르블랑 페어, 2-1에 약할 때 | 티모: 보건 / 쇼진 / 철퇴 |
| 나무정령 이즈·아펠 (Fast 8) | 덩정이 겹칠 때. 나무정령 상징이면 최고 | 아펠: 구인수 / 크라켄 / 인피 |
| 처형자 카직스 (7렙) | 럭키 카직스, 나 혼자. 고티어 1위라 연습용 | 카직스: 정손 / 라바돈 / 밤끝 |

| 선봉대 모르가나 (Fast 9) | **저티어 점수용.** 지팡이·여눈 많고 피관리 잘 된 판 | 몰가: 모렐 / 라바돈 / 공허 |

> 모르가나·티모는 플래~다이아 로비에서 센 덱이에요. 그마 이상에선 약해지니까 그때는 덩정·이즈아펠·카직스로.

**판 끝나고 30초**: ① 2-1 결정했나 ② 3-1 몇 골이었나 ③ 4-2 롤 후 몇 골 남았나 ④ 치감·깎 있었나 ⑤ 7~8등 원인이 피·돈·템·겹침 중 뭐였나

**컨디션 안 좋을 때 2연속 박으면 끄기.** 8등할 판도 7등으로 올리기.
