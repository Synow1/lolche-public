# 롤체 노트 앱 업데이트

개인용 TFT 공략 앱의 업데이트 파일이에요. 앱이 켜질 때 `manifest.json`을 보고 알아서 받아요.

- `data.zip`: 페이지·일일 덱 통계 (~0.5MB, 설치 없이 바로 적용)
- `assets.zip`: 아이콘·폰트·이미지·지난 시즌 사전 (해시 변경 시에만 다운로드)
- `www.zip`: 구버전 앱 호환용 전체 묶음
- `lolche-note.apk`: 앱 (앱 기능이 바뀔 때만 설치 확인)
- `src/`: 협업용 소스 사본 (페이지 조각·앱 코드·스크립트·문서). 올릴 때마다 원본에서 새로 복사돼요. 고칠 때는 최신 main 기준 patch로 보내 주세요
